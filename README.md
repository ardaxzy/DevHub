# DevHub

DevHub, geliştiricilerin proje keşfetmesini, ortak bulmasını ve birlikte üretmesini kolaylaştıran açık kaynak topluluk platformudur.

## Neden?

İyi fikirler çoğu zaman doğru insanlara ulaşamadığı için yarım kalır. DevHub; küçük fikirlere görünürlük, katkıcı arayan projelere de erişilebilir bir başlangıç noktası sunmayı hedefler.

## Özellikler

- Proje keşfi ve teknoloji filtresi
- Geliştirici profilleri ve iş birliği eşleşmesi
- Ekip oluşturma ve açık rol listeleri
- GitHub profili entegrasyonu

İlk sürüm proje keşfi ekranını içerir. Profil, ekip ve entegrasyon özellikleri yol haritasındadır.

## Başlatma

```bash
npm install
npm run dev
```

Tarayıcıda [http://localhost:3000](http://localhost:3000) adresini açın.

## Katkı

Yeni başlayan katkılara açığız. Başlamadan önce [CONTRIBUTING.md](CONTRIBUTING.md) dosyasını okuyun. İyi ilk konular için GitHub Issues altında `good first issue` etiketini takip edin.
