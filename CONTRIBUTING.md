# Katkı Rehberi

Katkı yapmak için teşekkürler.

1. Bir issue seçin veya büyük değişiklikten önce yeni issue açın.
2. Depoyu fork edin ve açıklayıcı isimli bir branch oluşturun.
3. Değişikliği küçük ve odaklı tutun.
4. `npm run build -- --webpack` ile doğrulayın.
5. Ne değiştiğini ve nasıl test ettiğinizi açıklayan bir pull request açın.

İlk katkı için `good first issue`, tasarım için `design`, yardım istenen işler için `help wanted` etiketlerini kullanıyoruz.

## Standartlar

- Arayüz metinleri Türkçe olmalı.
- Klavye ile kullanılabilirlik ve mobil görünüm korunmalı.
- Yeni bağımlılık yalnızca gerekli olduğunda eklenmeli.
